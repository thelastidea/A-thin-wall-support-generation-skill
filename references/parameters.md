# 参数、口径与踩坑

## 1. 参数表（v2：任意折线口）

| 项 | 默认 | 说明 |
|---|---|---|
| `layer` | 0.2 | 层高，**每次必问**；缝宽全部由它派生 |
| `lw` | 0.4 | 线宽，**每次必问**；决定张开封顶、薄墙片宽、最小可打印缝 |
| `skin` | 0.45 | 膜厚，由使用者给 |
| `wall` | 3.0 | 墙厚，只用于张开封顶 |
| `up` | `(0,1)` | 口平面内的 `up_dir`，每轮由使用者给 |
| `gap_side` | `None` | 非张开侧缝宽；`None` → `3×layer` |
| `gap_up` | — | **派生量，不是参数**：上缘缝宽 ≡ `4×layer` |
| `flare` | `True` | 上缘是否张开；`False` 时上缘与其余段同宽 `3×layer` |
| `flare_deg` | 30 | 张开坡度，只用来算 `run` |
| `flare_wmax` | 6.0 | 张开最宽上限 |
| `post_w` | 2.0 | 上缘张开柱宽（定死 2mm，沿墙切线方向） |
| `post_b` | 2.0 | 下缘直条柱**沿边**宽（定死 2mm；柱的长边竖直、沿打印轴 +v） |
| `rib_w` | `None` | 薄墙片宽；`None` → `lw` |
| `span_max` | 3.0 | 允许净跨上限（柱边到柱边） |
| `miter_limit` | 2.0 | 膜拐角 Miter 截断 |
| `overshoot` | 2.5 | 切口沿墙体法向溢出 |
| `overlap` | 0.0 | 连接件近端向膜内的重叠量；0 = 柱顶与膜下沿齐平（共面布尔仍并成一片） |
| `embed` | 0.1 | 连接件远端埋进墙 |
| `gap_floor` | `None` | 窄处可收窄到的下限；`None` → `max(lw, 0.4)` |
| `link_posts` | `True` | 判 link 的起膜边：改「两端各一颗竖柱 + 中间按 `start_gap` 铺」（`False` = 走老规则 `span_max`+`post_b`） |
| `start_w` | `None` | 柱的竖直总长；**`None` = 算出来**：`(缝 + embed)/cos`，直线底边就是 `0.6 + 0.1 = 0.7`（漏在缝里 0.6 = 一段缝高、咬进墙 0.1），杆顶停在膜端面、不进膜。填数字才会覆盖 |
| `start_gap` | 3.0 | `link_posts` 生效时相邻两柱**之间留的空**（不是中心距；中心距 = `post_b` + 实际间隙 = 2.0 + 约 3.0 ≈ 5.0） |
| `rib_t` | `None` | 侧边薄墙片在墙厚方向的厚度；`None` → 与膜同厚 `skin`。**新件显式给 `= lw`**（一条线宽），侧片断面即“线宽 × 层高”；给到比线宽窄会造细颈、切片排线偏一边 |
| `rib_w` | `None` | 侧边薄墙片**沿缝（该处切向）的宽度**；`None` → `lw`。给值常给 **= 层高**（0.2）。切片里侧片“占几层”看的是这一个，不是 `rib_t`：宽度轴就是 `up`，0.45 占 2.25 层（显示 2~3 层），0.2 正好一层 |
| `rib_snap` | `False` | 侧片柱心对齐层高网格：`True` 时把柱心沿膜轮廓挪到层带中心 `(k+0.5)×layer`，使侧片整好落在一条层带里（前提 `rib_w ≤ layer`） |
| `conn_fuse` | `0.0` | 连接件穿进膜的深度；`0` → 被膜裁齐、与膜**共面对接**。`>0`（0.1~0.2）→ 裁切用的膜整体内缩该值，连接件穿进膜、**先与膜并成一块再并面板**，界面是体积重叠 |
| `flare_tack` | 0.0 | 张开柱贴墙端离墙的空档（毫米绝对值）；`0` → 末端埋进墙 `embed`。`>0` → 末端停在离墙面该值处（`s_far = 4×layer − tack`），不再咬墙，弱连接 |
| `flare_tack_k` | 0.0 | 同上但按**层高倍数**给：`tack = k×layer`，常用 `0.8`（层高 0.2 → 0.16）。层高会变就用这个；与 `flare_tack` 同时给时后者优先 |
| `conn_fuse_k` | 0.0 | `conn_fuse` 按**线宽倍数**给：`fuse = k×lw`，常用 `1/3`（线宽 0.45 → 0.15）；实际深度压到 `skin/2` 以内 |
| `oblique_deg` | `45.0` | **上/下缘判定容差角**：外法向与 ±`up` 的夹角 ≤ 该值才算上缘/下缘，其余一律算侧边（横条）。45° 是默认老口径——36° 的星形斜边会在这一侧被判成“下缘”，放 2.0 宽竖直柱；改 30° 后斜边转侧边、全走横条（多边形/星形实测，见 §3） |
| `tip_deg` | `0.0` | **尖角判定角**（0 = 关）：膜轮廓内角 < 该值算尖角。尖角两侧不留端柱；尖角处按 `tip_mode` 放一枚尖角件（默认 `bar`：横条同尺寸、轴线只摆 up/hz，上尖竖直、其余水平）。星形 36° 尖角给 60 |
| `tip_embed` | `None` | `bar` 型尖角件末端咬墙量；`None` = 用 `embed`，`0` = 只贴墙面 |
| `tip_overlap` | `0.25` | `bar` 型尖角件起点往膜里挪多少；`0` = 起点正好在膜尖点上 |

**`tack` 作为默认已废**：上缘末端默认恒为 `gap_up + embed` 贴墙，不存在随手可用的弱连接选项。要“张开柱不碰墙”只能显式给 `flare_tack`（见 §3、§5 第 18 条），且必须核 `bodies == 1`。

## 2. 缝宽的两类与推导

```
gap_side = 3*layer                      # 其余所有段
gap_up   = 4*layer                      # 上缘，硬口径，不由 run 反算

W_top = min(flare_wmax, wall − lw)      # 柱子顶到墙面的接触面宽（每侧留 0.2）
grow  = (W_top − skin)/2                # 每侧张开量
run   = grow / tan(flare_deg)           # 30° 坡度需要的长度
s_wide = gap_up + embed                 # 张开柱贴墙端的位置（从膜边起算）
s_tip  = s_wide − run                   # 坡根；**可为负 = 柱子加长、多出的那截压进膜里**
```

**起膜边不是第三类缝宽。** 外法向朝下（`≥135°`）的那几段膜边是打印时的起膜边（膜在那里悬空起步、下方是空或水平面），但它的缝宽**仍是 `gap_side`**。曾经试过一律加宽到 `5×layer`（1.0）——**已否**：不符合“缝宽只有两类”的口径，而且并不是所有位置都需要（膜边本身是倒三角、下方是斜面的那种就不需要）。下垂靠自己加支撑或局部联结来解决，见第 14 条。

算例（layer 0.2 / lw 0.4 / wall 3.0 / skin 0.45）：

| 量 | 值 |
|---|---|
| `W_top` | `min(6, 3.0−0.4)` = **2.60** |
| `grow` | (2.60−0.45)/2 = **1.075** |
| `run` | 1.075/tan30° = **1.862** |
| 上缘缝宽 | **0.80**（= 4×0.2） |
| 其余缝宽 | **0.60**（= 3×0.2） |
| `s_wide` | 0.8 + 0.1 = **0.90** |
| `s_tip` | 0.9 − 1.862 = **−0.962**（柱子比缝长 0.96，坡根压在膜上） |

薄墙（1.6 墙厚）时 `W_top = min(6, 1.6−0.4) = 1.20`，`grow = 0.375`，`run ≈ 0.65`，`s_tip = 0.9 − 0.65 = 0.25`（仍在缝里）。坡度 30°、接触面 1.20。

**`W_top` 按 `wall − lw`（使用者定死）**：算例 2.6 的接触面、每侧只留 0.2 边距。旧口径 `wall − 2*lw = 2.2` 已作废——旧理由是“留半个线宽会把张开柱焊到窗口内壁上”，现按新口径实做：2.6 的楔形埋在墙里 0.1、离两侧外表面各 0.2，几何闭合、单片；但 0.2 < 一个线宽，切片时要专门看接触面外缘那一圈会不会被抹平。

**缝宽钉死 4×layer 的代价**：可用的贴墙距离只有 0.90，整段 30° 斜坡放不下。处理方式是“柱子加长、坡根压进膜里”（`s_tip < 0`，算例 −0.962），多出的那截楔形整段压在膜上，靠这截体积融合，于是 30° 与 `W_top = 2.6` 同时成立。曾经的做法是把 `s_tip` 夹到 0 并反算 `grow`，最宽只剩 1.74——这条路已废弃。

## 3. 分区与连接件

| 段外法向与 `up` 的夹角 | 分区 | 连接件 | 宽度 | 跨缝长度 |
|---|---|---|---|---|
| ≤45° | 上缘 | 张开柱（靠墙端摊到 `W_top`，坡跟该处法向） | `post_w` 2.0 | 缝 0.8 + 咬墙 0.1，再加坡根退进膜里 0.96；`flare_tack>0` → 离墙 `tack`、不咬墙 |
| ≥135° | 下缘 | 直条柱（竖直、⊥ 水平面） | `post_b` 2.0 | 算出 `(缝 0.6 + 0.1)/cos`，直线底边 0.7 |
| 其余 | 侧边/斜边/拐角 | 薄墙片（长边水平） | `lw` 0.4 | 算出 `(缝 0.6 + 0.1)/cos`，够到墙即止；厚默认 `skin`，`rib_t` 给值则居中等厚 |

- 布点沿**膜的收缩后轮廓**弧长（`membrane_cs.to_polygons()`），**不是口轮廓**。膜边已内缩 `g_used`，两者弧长不同，按口轮廓算会与柱脚错位
- `k = ceil(L / (span_max + w))`，区间两端各一颗，所以实际净跨 ≤ 3
- **一个拐角只留一颗柱（凸角）**：两个分区在同一个拐角各落一颗时，两颗都把拐角处那片缝挡住，会夹出一个封闭空腔（凸台左上角实测 0.55×0.55，图上像“左右连成一块”、缝绕不过去）。规则：只留较宽的那颗（同宽时 `down` > `up` > `side`），另一颗退场；三角（凸台/矩形/拱顶）实测小空腔从每角 1 个降到 0
- **凹角两侧都不放柱**：凹角（材料只占一个象限、洞的内角 270°）上那颗柱没法只靠“贴”连住墙——角格只有 `g×g`，柱宽 2.0 比它大，要连墙只能从侧面钻进墙角（工字形实测钻 0.1，图上就是“柱子的侧面跟墙贴着”）。所以凹角一律留空：`_stations()` 按叉积符号认凹角，`keep_first/keep_last` 两侧同时置 False，角格 0.6×0.6 空着，由两臂最近的那颗夹住（空口 0.6 会被间隙填充吃掉）。工字形实测 213 颗、142.24 cm³、`bodies=1`、闭合
- **段界**（分区切换点）那颗**就落在拐角上**：柱心离段端 `w/2`，柱端面与膜端面（膜轮廓拐角，已比口线内缩 `g`）**共面**，不越过拐角。别往外多跨——旧版跨 0.05 就伸进口线那格 0.6×0.6 拐角，图上柱和墙连成一块（凸台左上角实测柱占 25..27、与 u=25 的墙面粘死）；退 `w/2 + 0.1` 又留 0.1×0.1 封闭小空腔（图上像“柱没连到膜”）。正好 `w/2` 实测：柱面与膜面同落 u=25.6、凸台尖同落 u=68.6，0.6 那格留空，小空腔 0，十例仍 PASS。只在**凸角**成立；凹角按上一条留空
- **拐点不布**：尖角由相邻两颗夹住；放在尖角上的连接件没有唯一法向，所以不做“角平分线”这条额外规则
- **闭合轮廓从“区段起点”起算**：s=0 若落在某段中间，这一段会被拆成首尾两半，段界去重各删一颗 → 圆形口实测在下缘正中留了 7.4 的纯缺口（最该有支撑的地方）。`_stations()` 现在先把环转到一个分区切换点上再切 runs，返回前把 s 换算回原参数系。修完圆形口最大柱距 4.88（= 2.0 + 2.88）
- 岛（内环）走同一套判定；判定时按面积符号翻 `flip`，否则岛的上缘会被打成直条柱

### 圆形/曲线口（R=40、180 段离散，实测）

| 分区 | 连接件 | 实测 |
|---|---|---|
| 下弧（起膜边，约 98°） | 竖直柱 2.00×0.70（宽 2.0、高＝0.6 跨缝＋0.1 咬墙） | 13 颗，柱心距 ≈5.0 |
| 侧弧（各约 90°） | 0.4 薄墙片，长边水平 | 共 35 颗，长 0.70（45° 处自动放长到 0.93） |
| 上弧（约 98°） | 张开柱 宽 2.0（顶厚 2.6、坡长 1.86，跟该处缝） | 14 颗 |

- 方向按打印轴：下弧柱 13 颗**全是** `u 2.00 × v 0.70` 的短柱（含 ±40° 那些斜位置），侧弧薄片全是横条；下弧柱顶停在膜端面（v=60.6）、脚到 59.9
- 闭合（`closed=True`，无边界边）、1 片、167.18 cm³；`clean_export` 后仍闭合；无 <1.2mm² 夹缝
- 剖面里两条连接件之间那段 0.6 宽的缝**本来就是一个闭合小环**（面积 ≈2.3mm²）：这是“缝段”，不是缺陷，切片器的间隙填充会把它填实；判缺陷的口径要看**面积与最小边**：真正的夹缝是 0.1 级（凸台角实测 0.55×0.55 / 0.303mm²），而凹角处两条缝段汇合的端头口袋有成 1.0mm²（工字形 (120,60) 实测 1.0181 / 0.9511mm²，宽 0.6、长 2.26，y=1.2 时消失）也属正常。所以阈值用「面积 <0.5 或最小边 <0.2」，单看 <1.2 会误报
- `start_plan()` 仍按**单条边**逐条判，圆形 180 段会给出 45 条 1.4mm 的边、判 `none`/`link` 混杂；几何走的是合并后的区段。要看圆形口的判定，得把 `start_plan` 也改成按区段（待办）

- 楔的代价：尖角附近那个 V 被填实、没有缝（这是“端面在膜端点 + 侧面不跨膜”的必然结果——36° 尖角处膜的宽度为 0，任何宽度 >0 的矩形柱都必然左右越出膜）
- **v5 窄舌（已废）**：宽 = 缝宽 0.6、沿角平分线、起点按“半宽/tan(半角)”埋进膜 1.07、末端多伸 0.92 让两角都埋进墙。81 件、25.3895 cm³、水密；但被使用者否掉（不要沿角平分线的斜件）
- **v6 尖角横件（`tip_mode=bar`，使用者拍板）**：断面与横条一致（0.2 × 0.45），长度从膜尖点跨到墙，轴线只摆 up/hz：臂尖（17.8°、162.2°）与下尖（−54°、−126°）给水平件、上尖（90°）给竖直件（“下尖横、上尖不横”）。带咬合那版（膜侧 0.25 / 墙侧 embed 0.1）：81 件、25.3872 cm³
- **v7 同一版但两端都不咬合**（`tip_embed=0, tip_overlap=0`）：81 件、25.3872 cm³、`bodies=1`、闭合水密。**这就是使用者定版的口径**（当面答复“不留”）——与墙仍有楔形体积重叠（端面斜着切进墙料），与膜只剩膜尖那一个点的接触，膜尖在打印上是孤立的，这个代价使用者已接受，后续别再加膜侧咬合
- **为什么 36° 斜边会被判成“下缘”（用户实测提问）**：分区只看外法向与 `up` 的夹角。判据是「夹角 ≤ `oblique_deg` 才算上/下缘，其余算侧边」，36° 比默认 45° 小 → 算下缘 → 放 2.0 宽竖直柱；而拐下去那条是 72° → 算侧边 → 放横条。两条边几何上都合理，但同一颗星上“竖柱/横条”混着出现，看上去就是“上部分是竖柱、下部分是横条”。给 `oblique_deg=30` 后 36° > 30° → 四条斜边全部归侧边、统一横条
- 代价（换横条后要认的账）：斜边上接触面积从 5×2.0=10mm 降到 8×0.2=1.6mm（沿 27mm 边），一条层高厚（0.2）、间距 3.5；要更牢就压 `span_max`（3.0 → 2.0 会加密到 12 颗左右）
- **36° 尖角**：膜端被 `miter_limit=2.0` 截平（理论位移 0.6/sin18°=1.94 > 2×0.6=1.2），顶角处膜端离口尖约 1.9mm、是平头；两侧缝仍 0.6。尖角正中放随形楔（`tip_deg` 开启时），顶点在膜顶点、两侧贴膜的两臂、外端埋墙；尖角两侧的端柱按弧长滤掉
- **252° 凹角**（5 个）：角格留空、照旧不放连接件，缝顺着拐过去（放大剖面上能直接看到角格是空的）
- 回归用例 `五角星_尖角凹角`（200×300 板、R=90、默认 45°）：`bodies=1`、闭合、156.76 cm³、非流形边 1

## 4. 融合与撕脱
- 连接件**近端与膜边齐平**（`overlap` 默认 0）、远端**埋进墙** `embed` 0.1：近端面贴面也能被 manifold 布尔并成一片（六形状实测单片、闭合）；远端一旦也设 0 就会脱开——实测拱顶裂成 11 片、异型带凹口 2 片。所以“两边都齐平”不成立，只能膜侧齐平。近端齐平是刻意取舍：柱不往膜里多伸，代价是导出网格出现零面积面（见 §6 第 16 条）
- 张开柱的楔形整段压在膜上时，把膜的 `[m0, m1]` 全包住，融合由这个体积重叠保证，与 `overlap` 无关
- 撕断点：连接件远端埋进墙、近端并进膜，两侧都是 90° 内角，断点落在哪一端由应力决定；要“窗口干净”就得给连接件做缩颈，那是另一套代价

## 5. 已踩过的失败模式

1. **膜悬空（`bodies ≥ 2`）**：连接件只到膜边、不重叠 → 膜整片脱落。v2 靠**远端** `embed` 穿透墙 + **近端齐平**（`overlap=0`）解决。**每次都要数连通体。**
2. **共面≠融合**：两个实体只共享一个面时，`manifold` 仍视为两个体。所有连接必须做体积重叠。
3. **切口溢出方向**：`overshoot` 只沿墙体法向，平面内不许溢出，否则口被放大、缝宽全错。
4. **张开凸出墙外**：张开断面超过墙厚会撞相邻件（历史实测 0.055 cm³ 干涉）。`W_top` 已内置封顶。
5. **只封了一面**：中段/外套这类前后两面都露在外面的件，两面各做一份。
6. **非流形边（重载后 `watertight=False`）**：STL 是 float32。→ `clean_export()`（manifold 重绕 + `merge_vertices(digits_vertex=6)`），导出后重新载入复查。
7. **统计连通体用错 API**：本机 trimesh 无 graph 引擎，`mesh.split()` 抛 `no graph engines available`。→ 用 `manifold3d.Manifold(...).decompose()`。
8. **把封膜的口当出口**：膜 + 缝挡不住纸包，若索引里是“出包口”，必须先告知“要捅破/剪开”。
9. **窄处残条**：窄口触发收窄（`g_used < 3×layer`）时，早期按 `3×layer` 切上缘环带，会留一条 `(3×layer − g_used)` 宽的膜残条。现在的做法按 `4×layer − g_used` 挪边线，缝宽恒为 `4×layer`，不存在残条。
10. **上缘一弯，膜被割碎**：早期用「逐段 quad 并集 + 端头沿切线外伸」切环带。只有上缘是单一直段时，环带内边才与膜的 miter 轮廓重合；上缘由多段方向不同的线组成（拱顶、正弦波、斜切角）时，两者逐段错开，膜被割成锯齿乃至碎块（实测拱顶 1→4 片、正弦波顶 1→11 片，布尔随即报 `Not all meshes are volumes`，其中还夹杂零体积三角片）。已改为**先挪上缘边线再统一 offset 一次**，七种上缘形状（矩形/梯形/拱顶/正弦波/浅V/凹口/岛环）全部 `bodies=1`。
11. **收窄与张开互斥**：窄口 + 张开会在加宽处把膜刮光并**报错**（这是正确行为，不是 bug）。判据：局部净宽需 ≥ `g_used + 4×layer + 最小残留膜宽`；标准参数下 ≈ 1.8 mm，而收窄只在 ≤ 1.2 mm 时发生，两区间不相交。窄口要么放宽，要么 `flare=False`。
12. **`flare=False` 的缝宽**：不张开时上缘必须回落到 `g_used`，不能仍用 `4×layer`，否则柱会多埋进墙 `(gap_up − g_used)`。已按此实现。
13. **膜被割碎是静默的**：早期加宽后只查 `is_empty()`，膜裂成几片照样放行，现象伪装成“柱子生成得奇怪”。现在 `num_contour` 必须等于输入环数（岛环算 1 片），否则报错并给出判据与两条出路。
14. **起膜边悬空下垂 → 该段的柱加密（已落地）**：膜在水平面上方 0.6 处起步，首层下垂 ≈1 层高（0.2），余量只剩 0.4；且 0.6 < `2×lw = 0.8` 落在切片器间隙填充区间。**一律加宽到 `5×layer` 已被否**（上一版试过，实测凸台上表面 0.6→1.0 生效，但不符合“两类缝宽”口径，且倒三角这类膜边不需要）。三条候选：
    - **两端定柱 + 中间按间隙铺**（**已实现，默认开**：`link_posts=True`、`start_w=None`（按缝算）、`start_gap=3.0`）：柱本来就是“柱脚埋进下方材料、柱顶与膜下沿齐平”，问题只是**太疏**（老规则 1.0 宽、中心距 3.9，两柱之间的膜悬空 2.9）。现改为：柱是**竖直柱**（长边 = 打印轴 +v，⊥ 水平面），**宽 2.0 定死**，**竖直长是算出来的**——`(缝 + embed)/cos`，直线底边 = `0.6 + 0.1 = 0.7`（露在缝里 0.6 正好一段缝高、咬进墙 0.1），**杆顶停在膜端面、不进膜**；先落该段两端各一颗（柱心离段端 `w/2`，柱端面与膜端面共面），剩余净长 `L − 2d − w` 再按柱间空 3.0 均分（`m = round((净长 − 3)/(2+3))`，实际间隙 `(净长 − m·w)/(m+1)`）。实测：方形口 100×100 起膜边 20 颗 @4.9（首柱 25.6..27.6、柱顶 v=30.6 在膜端面、脚到 29.9）；工字形 v=30 24 颗 @4.92、v=220 两段各 8；圆形口 13 颗 @5.0 且斜位置仍竖直（2.00×0.70）。缝仍在。**注意宽 2.0 + 空 3.0 = 5.0，正好等于 `span_max 3.0 + 宽 2.0`**，判 link 的段与老规则布点几乎重合（矩形两种口径体积都是 91.97），差别只剩柱是竖的还是跟法向。
    - **合缝**（`seal_start`，试过、**已撤**）：把那条起膜边朝外拉长 `g_used + embed` 落到下方材料上，膜厚不变。首层确实不悬空了，体积 97.34→97.40，但**这条边上的缝整条消失**，用户看过图后改主意：要柱子、缝留着。
    - **全墙厚厚条**（已否）：把起膜边那一圈做成 3.0 全墙厚、0.2~0.4 高。它是悬在 0.6 空档上的台子，只在墙两外表面留一道梗，看第一版图即否。
    **选哪条，照切片器“要不要生成支撑”的四条判据**（与 Orca/Bambu/Prusa 同构）：悬垂角 ≥45° 才生成支撑；跨度在 `max_bridge_length` 内按桥处理、不生成支撑；落差 ≤ `z_distance` 不生成支撑；悬空周长小于阈值不生成。映射成动作：`none`（尖点/桥接）/ `post`（柱距收到 `bridge_max`≈3）/ `link`（落差贴脸，柱子救不了，改加密柱）。**这里 `z_distance` 取 `2×lw`（间隙填充距离，算例 0.8）而不是切片器默认的 0.2~0.3**：缝本来就会被填满，落差小于一整个缝距就等于贴脸。`start_plan()` 逐条算出这组 `(段长, 倾角, 落差, 动作)`，结果在 `info["plan"]`。算例：凸台 h=6 / 矩形 / 拱顶的起膜边落差都是 `g0`=0.6 ≤ 0.8，全判 `link`（长 43 或 150、倾角 0°）。`post` 只给判定，不改几何。
    - **只作用于判 link 的段**：落差 > `2×lw` 时（实测 `gap_side=1.2`）同一形状判 `post`，柱距仍按 `span_max`，与 `link_posts=False` 的结果一致。
15. **窄通道把膜整条抹掉 → 已改为显式报错**：相对两条边净距 < `两侧缝宽 + lw`（算例 `0.6 + 0.8 + 0.4 = 1.8`）时，内缩后那段膜整条消失而 `num_contour` 不变。早先实测 h 扫描：h=1.2/1.4 上方全空、1.6 只剩极窄一条、1.8/2.0 窄条且位置漂移、≥2.5 正常，全程不报错。现在 `_check_too_narrow()` 在生成时直接抛 `离顶部过窄`，并给出所需净宽。→ 遇到就改形状（抬高或让开），不要指望膜自己活下来。
16. **「完全共面」会带来零面积面与 4 面边，但不是缺陷（口径已改）**：连接件顶面/底面与膜同厚齐平、端面与膜端面共面，manifold 把共面区并成一块后三角化，会吐出零面积楔形与重复面。实测：矩形 / 圆形 / 异型 / 岛环 / 拱顶 **0 个**；工字形（有凹角）**164 个零面积面 + 15 条 4 面边**，全压在 v=60 / v=220 两排柱的直线上，`bodies` 仍 1、体积 142.1096 不变。柱沿厚度各缩 0.002 就降到 11 个（残余 14 条 4 面边是重复面，不是洞），但柱面会比膜面低 0.002 出现一道浅槽——不值。**零面积三角形不能删**：删掉立刻开出 184 条边界边（它们本身在堵缝）。所以：判缺陷用 `closed`（无 1 面边界边）+ `bodies==1`，`watertight` 只作参考；`check()` 已同时返回 `closed / holes / nonmanifold`。上一版记的“凸台导出非水密（未修）”与工字形同源，已按此口径收编
17. **凹角那颗柱必须留空（已落地）**：凹角处材料只占一个象限，角格 0.6×0.6 之外就是材料；柱宽 2.0 大于角格，又要跟墙连上，只能从侧面钻进墙角 0.1（工字形实测 u 到 120.1、柱右面埋在墙里），同一颗柱的左面还压在膜端面 u=119.4 上。→ `_stations()` 认凹角（叉积符号 × 环面积符号 < 0）后两侧都不放柱，角格留空。凸角（凸台尖端 25.6 / 68.6）不受影响

18. **侧片削薄到一层（`rib_t`）与张开柱离墙（`flare_tack`）**——两条都是使用者提的显式口径，默认都关（`rib_t=None`、`flare_tack=0`），老件口径不变（加完后 `demo-poly` 十例仍全 PASS：91.97 / 167.18 / 142.24 / 91.15 / 111.59 …与定版逐位一致）。
    - `rib_t = 0.2`（一层层高）：侧片居中 1.4–1.6（膜 1.275–1.725），沿边宽仍 `lw` 0.45、跨缝长仍 0.7（0.6 跨缝 + 0.1 咬墙）；与膜相接两侧各留 0.125 台阶。R40 实测 35 片，`bodies=1`、闭合、17.176 cm³（同厚版 17.1786，只少 2.4 mm³，正好是 35 片削薄的部分）。片薄后是**单层悬带**，跨 0.6 只当短桥，不要按柱看。**口径已收回**：0.2 比线宽窄，切片排线只能贴边 → 走线偏一边，见第 19 条末
    - `flare_tack = 0.16`：`s_far = 4×layer − tack`。坡长恒 = `run`（1.818），所以牙整体朝口内平移 `embed + tack = 0.26`，压膜那截 0.918 → 1.178，`W_top` 2.55 与 30° 都不变；牙顶端面离墙面 0.16、不再咬墙。R40 实测 14 颗、`bodies=1`、闭合、17.181 cm³。此时**上缘只挂在膜上**（靠 35 片侧片 + 13 颗下缘柱锚墙），撕脱从顶边起，正是要的“从上面好撕”。
    - **打印关（必须看）**：`tack < 层高` 时能不能真断开取决于空档落在哪一层。正对顶部那颗实测牙顶 Z=89.84、墙面 90.0、层边界 89.8/90.0 → 中间空一整层，能断开；±40° 那几颗空档是斜的，竖直只剩 ≈0.11，层内成了 0.16 宽的窄条，会被间隙填充（`2×lw` = 0.9）焊上。要整圈 14 颗都断开：关间隙填充，或把 `flare_tack` 提到 0.2~0.25。

19. **侧片“一层”到底该削哪个方向（`rib_w` / `rib_snap`）**：`rib_t = 0.2` 削的是**墙厚方向**（横向，切片里看不出来），侧片在竖直方向仍占 `lw` 0.45 → 用户看切片时问“侧面连接件还有 2 层与 3 层”。原因：侧片的宽度轴就是 `up`（打印层高方向），0.45 / 0.2 = 2.25 层，压进 3 个层带（端点正好落在 `layer` 整数倍上时才是 2 个）。**要“只占一层”得削 `rib_w`**：
    - `rib_w = layer` 0.2 → 断面 0.2×0.2 = 0.04 mm²（原 0.45×0.2 = 0.09），R40 实测侧片 35 → **37 片**、净空 3.0~3.26、`bodies=1`、闭合、**17.1803 cm³**（比 0.45×0.2 版 17.1813 只少 1 mm³）
    - `rib_snap = True` → 柱心沿膜轮廓挪到 `(k+0.5)×layer`，R40 实测 **37/37** 全落在层带中心；STL 里侧片外侧面（Y=1.60）的 Z 起止正好是 `119×0.2` 与 `376×0.2`，即每片整好一条层带
    - **只能沿切向挪**：切向 = `(-ny, nx)`，`Δs = Δh / (切向·up)`；法向挪会改跨缝长度，挪 0.1 就少 0.1 咬墙/多 0.1 退膜。侧弧切向·up 在 0.707~1 之间，所以最大挪 0.14（弧长）
    - 守卫：离段端 `d = w/2` 以内那颗不挪（保“端面与膜端面共面”），换形状时按校验第 14 条重核
    - 竖直方向“每处都正好一层”做不到全覆盖：±40° 处口沿切向的竖直分量只有 ≈0.77，0.2 的宽在那里只占 0.15（不足一层）。要严格一层得按 `层高/竖直分量` 逐段放大宽度，代价是片歪斜、断面不均，本轮没有采用
    - **`rib_t = layer` 这条要收回（实测踩坑）**：把侧片在墙厚方向削到 0.2，等于在膜与墙之间造了一条 **0.2 宽、0.45 长的细颈**（截面图见 0.45/0.2 两版的 `Z=43.9` 层横截面）。0.2 比线宽 0.45 窄，切片器排不下一条 0.45 的线，只能贴着细颈的一侧对齐 → 现象就是“薄墙的喷嘴走线朝一边歪”，而且那一层的墙与膜之间靠这条偏心的线连接、不再是一条直通墙。**要“侧片只占一层”，正确做法是保持 `rib_t` 默认（= 膜厚），只给 `rib_w = layer` + `rib_snap`**：侧片在墙厚方向与膜同宽，缝里那条线与膜同宽同中、直通到底。R40 实测（`rib_w=0.2, rib_t=None, conn_fuse=0.15`）：37 片、`bodies=1`、闭合、17.1815 cm³

20. **连接件与膜不许“共面对接”（`conn_fuse`）**：老口径是把连接件按膜 `difference` 一次——连接件被裁到膜端面为止，两者只**共面贴合**，布尔并出来的面在界面处是一对重合面（导出 STL 里表现为 2 条 4 面边）。要求“先生成连接处、再与薄墙合成一个整体”时改成 `conn_fuse > 0`：裁切用的膜整体内缩该值（`membrane_cs.offset(-conn_fuse)` 再成实体），连接件因此**穿进膜 0.1~0.2**，然后 `_union([膜, 连接件...])` 先并成一块、再并面板。实测 `fill` 从 16 片降到 **1 片**；R40 同参数体积 17.1803（对接）→ 17.1815（穿 0.15），差 0.0012 cm³ 只是界面那点重叠，外形与每层截面完全一致。
    - 为什么必须这么做：界面共面时切片器可能把 0.2 的连接件当**独立薄壁**单独排一条线（线宽 0.45 塞不进 0.2，只能偏一边）；穿进去并成一体后，缝里那条线是膜那条墙的延续
    - 内缩膜不能缩没了：`offset` 后 `num_contour` 不等于原值就退回不缩（薄岛/窄环要当心）
    - `conn_fuse` 默认仍是 `0`（老件口径不变，`demo-poly` 十二例全 PASS：91.97 / 167.18 / 142.23 / 159.58 / 91.15 / 111.59 / 179.74）；但 union 顺序已统一改成“先并膜+连接件、再并面板”，体积与逐位一致
21. **斜边被算成“下缘”，同一件上竖柱与横条混着（星形实测，用户指出）**：45° 容差把 36° 的斜边划到了下缘一侧（`dot=−0.81`），于是放 2.0 宽竖直柱；紧邻的 72° 边算侧边放横条，肉眼看着就是“一条边竖柱、旁边一条横条”。给 `oblique_deg=30` 即可让所有 ≥30° 的斜边统一走横条。**连带影响**：拐角那颗的让位规则按宽度+优先级比（`down > up > side`），斜边从 down 变 side 后，水平上缘的端柱不再让给邻居，每段从 5 颗变 6 颗；`侧片` 也随之从 33 涨到 68（四条斜边各 8/9）。接触面积从 10mm 掉到 1.6mm/边，要更牢就压 `span_max`
22. **柱的端面压在尖角上 → 左右侧面插进墙里（星形实测，用户指出“张开柱左侧也贴墙”）**：36° 尖角处缝是一个 V（膜尖端离口尖 1.94），2.0 宽的柱端面压在尖角上时，柱的左右侧面在 V 的两臂上各插进墙里一截，`flare_tack` 0.16 只管“末端到墙面的空档”，管不到侧面。给 `tip_deg=60` 后尖角两侧都不留端柱（最近件退到 3.17），切开后不再有柱压角。**顺带修一个老 bug**：`keep_first/keep_last` 只处理**区段两端**的角，同一区段内部拐过去的角管不到——星形两条斜边都是 side，顶角与底中 252° 角都在区段内部，各漏了 1 片（距角 0.04 / 0.07，端面直接插进墙）。现在按弧长再滤一遍（判据：件端面到角点 < `tack`）。**环境依赖**：`reflex_v` 与 `sharp_v` 都在旋转后的 ring 上算、`cum` 也是旋转后的，两边索引必须一致，否则角判定整体错位
23. **尖角处“端面在膜端点 + 侧面不跨过膜”只能靠随形楔（用户第二轮批注）**：矩形柱做不到——36° 尖角处膜的宽度为 0，任何宽度 >0 的柱，端面一放到膜顶点，左右两角就落在膜外、插进墙（实测：宽 1.0 的窄柱也越界）。楔的做法：顶点 P 沿角平分线往膜里退 `conn_fuse`（留体积重叠、避免共面对接），两条射线与膜的两条臂平行（各内收 `fuse`，所以永不越出膜），长度 `L=(g+embed)/sin(内角/2)+fuse`（36° 尖 ≈2.41，外端埋墙 0.1~0.2），厚度与膜同为 `m0..m1`。**为什么早先尖角上“没有柱”**（用户问过，三条原因）：① 布点沿膜轮廓撒、端柱按半柱宽内缩，区段端点正好落在尖角时柱端面就压在顶点上，不是“尖角不放柱”；② 更早（45° 口径）那颗被**拐角让位规则**剔掉了——一个拐角只留一颗、同宽时 `down > up > side`，尖角两侧是 2.0 下缘柱 + 2.0 张开柱，同宽则下缘柱胜、张开柱退场；③ 斜边改 0.2 横条后邻居变窄、张开柱不再让位，于是又回到尖角上并插墙。`reflex_v` 的“角格留空”只判内角 >180° 的凹角，36° 尖角从来不在那条规则里
24. **楔被否 → 尖角件按“横条同尺寸 + 轴对齐”落地（用户第四轮批注：不要填 V，用一个连接件把尖角处与墙连起来；尺寸跟之前连接件同一套逻辑；也要保持水平；下尖横、上尖不横）**：断面取 `rib_w`(0.2) × 膜厚(0.45)，长度用 `_march_out()` 从膜尖点量到**窗口外环**（= 墙料边界）再 +`tip_embed`；轴线只在 up / hz 里选，上尖给竖直、其余给水平。**别用“离膜边界 ≥ 缝宽”当量长的判据**——尖角是折线顶点，膜外一点的最近点就是那个顶点，会在缝里提前停住（实测顶尖那颗柱只走到 0.7、根本没碰墙）。两端都不咬合（`tip_embed=0, tip_overlap=0`，**使用者定版，不许再改**）的实测：与墙靠端面楔形切进墙料仍有体积重叠、`bodies=1` 过得去；与膜只剩膜尖一点接触（探针 dz=−0.05 处、x=膜尖−0.03 已是空），膜尖打印上孤立——该代价使用者已当面接受（“不留”）

### v2 实现层面踩到的几条（已修，别再犯）
- **剖面元组顺序**：`_profile` 返回 `(s, a)`（`s` 沿缝、`a` 沿墙厚），`_sweep_prof` 按 `(s, a)` 解包。写反了会得到“厚度方向错位 1.5mm 的柱”，`bodies` 直接炸开。
- **换轴是镜像**：`(X,Y,Z) → (u,a,v)` 这类置换行列式为 −1，必须翻面，否则零件体积为负、布尔报 `Not all meshes are volumes`。
- **退化剖面**：`run` 恰好等于缝宽时，张开剖面的直段长度为 0，会出现重合点 → 非水密。`_sweep_prof` 里已有去重。
- **内环判定要镜像**：孔环（岛）的材料在外侧，`(dy,-dx)` 指向的是岛而不是缝，“上缘”与“下缘”会整体反掉。`_stations` / `_widen_up` 里按轮廓面积符号取 `flip`，孔环翻转一次。
- **挪边线的顶点要截断**：上缘段往口内挪、邻段不挪时，顶点是两条移位后直线的交点；两段近乎共线时交点会飞出去（尖角处更甚）。`_widen_up` 里按 `|交点 − 原顶点| ≤ miter_limit × 移位量` 判，超了就用“平均位移”，否则移出来的折线自交、offset 又把它抹平成一团。
- **尖角被误判“离顶部过窄”（五角星实测踩到，已修）**：`_check_too_narrow` 用“两段外法向夹角 >135°”认“相对的两条边”。尖角处相邻两条边的外法向差 = 180°−尖角，**36° 的星尖就是 144°（dot=−0.81）**，于是被当成“相对的两条边”，两段还共用一个顶点、距离当然 0 → 直接抛“两条相对的边只隔 0.000”。修法：两段只要共用顶点（四个端点到对方段的距离有一个 ≈0）就不参与判定。回归里已加 `五角星_尖角凹角` 用例钉住它（`_rings_star`：10 边、5 个 36° 尖角、5 个 252° 凹角，200×300 板上 R=90）

### 预览脚本踩到的几条（已修）
- **画家算法不可用**：3mm 薄板用 `Poly3DCollection` 的 `zsort` 会出假遮挡与摩尔纹，看着像零件破了。脚本改为深度缓冲光栅化，并只出正投影/剖切。
- **裁切不能筛面片**：布尔后的大三角形质心在框里、顶点却横跨整块板，按质心筛会把视野撑回全宽。→ 只用裁切框定视野，靠像素边界与 z-buffer 截断。
- **剖面不能按线段中点裁**：一条横跨整个口的长边中点可能落在视野外，整条会被丢掉，剖面变空白。→ 只设 xlim/ylim，让 matplotlib 自己裁。
- **光照过曝**：`0.34 + 0.62×inten` 会把受光面画成纯白，像漏画的洞。→ 压到 `0.46 + 0.42×inten` 并叠一层景深色调。
- **依赖**：本机只有 matplotlib / PIL / trimesh / manifold3d，**没有** pyglet、pyrender、scipy。不要引入 `slice_mesh_plane`（要 scipy），用 `mesh_plane` 取线段。
