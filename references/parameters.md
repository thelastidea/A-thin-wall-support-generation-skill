# 参数、口径与踩坑（v2 / 0.08 层高版）

> 本文数值除注明外，一律取 `layer=0.2`、`lw=0.4`、`skin=0.45`、`wall=3.0`、`up=(0,1)`。凡标"实测"的都是真跑过 `demo-poly` 或 `test_small_layer.py` 的数。

## 0. 这一版改了什么（相对上一版）

1. **缝宽加了下限 `slot_min = 1.5×lw`**，`g0` 与 `gap_up` 都受它托底 —— 0.08 层高能用，靠的是这一条。
2. **`gfloor` 与 `slot_min` 拆开**（前者是"窄处能收到多窄"，后者是"缝最窄多少还能打"），窄口不再被误判死。
3. **净跨只剩一个口径** `clear_max`：膜首层要桥它、上方墙底面也要桥它，同一个数卡两头；`info["support"]` 逐区给出柱数、净跨、覆盖率、搭接面积。
4. **删除 `flare_wx`（沿边加宽旋钮）**：柱沿边恒 `post_w`=2.0，宽度不涨；上缘只靠柱数把净跨压到 ≤`span_max`（早期按加宽后排点会让柱 31→24→20，反而削弱膜上端锚点）。
5. **`oblique_deg` 全链路生效**（原来 `_check_too_narrow` / `_widen_up` / `start_plan` / 尖角件四处硬写 45°）。
6. **`print_risk()` 分三档**，不再对默认 0.6 缝每次都喊"会被间隙填充"。
7. **修默认参数下的崩溃**：`tip_mode=bar/zone` 且 `rib_w=None` 时 `0.5*spec.rib_w` 直接抛 TypeError（现走 `_rib_w()`）。
8. **`2×lw` 统一成 `gap_fill`**（原 954/1125/1163 三处各写一遍）。
9. **新增 `corner_deg`（默认 20°）**：相邻切线夹角 > 该值才算真拐角，圆弧上几百个离散顶点不再被误判成拐角/凹角；`_stations` 另加"短区段并进邻居"（短于 `max(1.0, 1.5·g_used)`），曲口不再切出"每 2 段一颗柱"的柱排。
10. **新增 `var_gap`（默认 False）**：变宽口（新月/泪滴/锥形槽）逐段压缝，窄端缝收到下限以下、该处膜与墙粘牢；柱长改按射线量到墙（`d_hit`）。见 §11。
11. **墙厚闸门 `max_wall`**：`wall ≥ max_wall`(默认 5.0) 时**不出件**（返回空 cut/fill，不抛错）——只在薄壁上做薄墙支撑，一处悬垂只加一套。
12. **补柱**（`_stations` 末尾）：角格留空滤掉柱后，同一区内净跨 > `span_max` 的段按 `ceil(净跨/(span_max+w))` 补到 ≤ `span_max`，落角格的点跳过。twelve 例体积因此 +0.01~0.02 cm³（blob down 4.77→1.38、波浪槽不再超标）。
13. **`clean_export` 先过 `_drop_inverted`**：剔除布尔留下的负体积碎片（只剔负体积，真脱落仍报错）。
14. 新增 `scripts/test_small_layer.py`：0.08/0.12/0.16/0.2 四档层高 × 六种口 + 口太窄闸门四档，四条断言，非零返回码即失败。
15. **新增口太窄闸门 `min_membrane`（默认 2.0）**：口内最宽处的可打膜宽（≈最大内切圆直径 − 2×侧缝）小于它就**不出件**（`info["skipped"]="membrane_too_narrow"`，不抛错）。量法见 §6：96×96 网格 + 偶奇判内 + 点到边距离取最大内切半径 `R`，判 `2R − 2·g0`。
16. **新增顶隙 `top_clear`（写死 0.16mm）**：上缘张开柱不再埋进墙，柱端离上方墙面 0.16（0.08 层高下正好 2 层，层高变了不跟着变）。托住悬垂面、把下垂量限在这个尺寸内，又不与它熔死；`0` 恢复老口径。见 §5.1、踩坑 32。
17. **凹角补柱**：补柱的落点若落在角格内，改成沿弧长挪到角格外侧最近处再补（不再整段放弃）。实测 STL 件「测试1.stl」的 down 净跨 6.673 → 2.59。

| `lw` | 0.4 | 线宽，**每次必问**；决定可打印缝宽下限、张开封顶、薄墙片宽、细颈判据 |

## 2. 派生量与算例

```
g0      = gap_side if 显式 else max(3*layer, slot_min)          # 缝侧
gap_up  = max(4*layer, g0 + layer)                              # 缝上，硬口径
slot_min= gap_min  if 显式 else 1.5*lw                          # 可打印缝宽下限
gfloor  = gap_floor if 显式 else max(lw, 0.4)                   # 窄处收窄下限
gap_fill= 2*lw                                                  # 间隙填充阈值
tack    = flare_tack if 显式 else flare_tack_k*layer
fuse    = min(conn_fuse if 显式 else conn_fuse_k*lw, skin/2)

w_top   = min(flare_wmax, wall - lw)        # 张开柱顶端（墙厚方向）
grow    = max(0, (w_top - skin)/2)          # 每侧张开量
run     = grow / tan(flare_deg)             # 坡长
s_wide  = d_hit - top_clear                  # 贴墙端（离上方墙面 2 层；d_hit = 射线量到的墙面距离）
s_tip   = s_wide - run                      # 坡根；可为负 = 多出来的楔形压进膜里
```

| 量 | layer 0.08 | 0.12 | 0.16 | 0.20 | 0.28 |
|---|---|---|---|---|---|
| `g0`（缝侧） | 0.600 | 0.600 | 0.600 | 0.600 | 0.840 |
| `gap_up`（缝上） | 0.680 | 0.720 | 0.760 | 0.800 | 1.120 |
| `w_top` | 2.60 | 2.60 | 2.60 | 2.60 | 2.60 |
| `grow` / `run` | 1.075 / 1.862 | 同左 | 同左 | 同左 | 同左 |

`w_top`/`grow`/`run` 只跟 `wall`、`lw`、`skin`、`flare_deg` 有关，**与层高无关**——层高变化只动缝宽与弱连接空档。

薄墙（1.6 墙厚）：`w_top = min(6, 1.6−0.4) = 1.20`，`grow = 0.375`，`run ≈ 0.65`，`s_tip = 0.9 − 0.65 = 0.25`（仍在缝里，没有压进膜）。

**`w_top` 按 `wall − lw`（使用者定死）**：算例 2.6 的接触面、每侧只留 0.2 边距。旧口径 `wall − 2*lw = 2.2` 已作废。2.6 的楔形埋在墙里 0.1、离两侧外表面各 0.2，几何闭合单片；但 0.2 < 一个线宽，切片时要专门看接触面外缘那一圈会不会被抹平。

**缝宽钉死 `4×layer` 的代价**：可用的贴墙距离只有 0.90，整段 30° 斜坡放不下（要 1.86）。处理方式是"柱子加长、坡根压进膜里"（`s_tip` 可为负，算例 −0.962），多出的那截楔形整段压在膜上靠体积融合。曾经把 `s_tip` 夹到 0 并反算 `grow`，最宽只剩 1.74 —— 那条路已废。

## 3. 缝宽：为什么是这两个数，以及 0.08 的下限

```
gap_side = max(3*layer, 1.5*lw)      # 其余所有段
gap_up   = max(4*layer, g0 + layer)  # 上缘，硬口径，不由 run 反算
```

**缝在打印机眼里是"水平间隙"**：两条竖直墙之间要留出一条能放下的挤出线，所以下限由**线宽**定，不由层高定。层高 0.2 时 `3×layer = 0.6 = 1.5×lw`，两套口径正好吻合（这就是老算例一直是 0.6 的原因）；层高降到 0.08 时 `3×layer` 只有 0.24 —— 比一条 0.4 的线还窄，切片器必然拿一条线把缝填死，膜和墙粘成一块，整个结构白做。所以由 `slot_min` 托底，`3×layer` 只在层高 ≥ 0.2 时才真正起作用。

- 想让缝更宽：给 `gap_min`（例如 0.8，代价是上缘柱顶更短的搭接余量、窄口更容易报"离顶部过窄"）。
- **`gfloor` 与 `slot_min` 必须分开**：`gfloor` 是"窄口被挤时能收到多窄"，`slot_min` 是"缝窄到多少仍能打"。混成一个数会判死本来能打的窄口。窄口由 `_shrink` 一步步收缝保膜，但**保住片数 ≠ 保得住可打的膜宽**：1.2 宽的槽在 0.6 缝下会被收到 0.58，膜只剩 0.04mm 一条，`closed`/`bodies` 全过、切片却打不出来。所以新一轮加了 `_min_residual()`：收窄后按"相对两边净距 − 两缝"算最窄膜宽，`< lw` 就出 `info["warn"]` 的"**残留膜过窄**"（1.2 → 0.04mm、1.4 → 0.20mm 会点名，1.6 → 0.40mm 刚好等于线宽不报）。收窄发生时另有一条"窄缝已收到下限"，说明这些缝会被切片器填死。
- **`gap_up` 永远比 `g0` 多一层**：上缘那条缝是膜顶端与上方墙底面的**竖直**间隙，它决定上方墙的底面要不要支撑；缝宽 ≥ 一层，切片器才把它判成"悬空 < 一层、不生成支撑"。`4×layer` 是经验值，只是现在不再单独说了。

**起膜边不是第三类缝宽。** 外法向朝下（≥135°）的那几段膜边是打印时的起膜边，但缝宽**仍是 `gap_side`**。曾试过一律加宽到 `5×layer` —— **已否**（不符合"缝宽只有两类"，且不是所有位置都需要）。下垂改由柱加密解决，见 §8 第 14 条。

## 4. 分区

| 段外法向与 `up` 的夹角 | 分区 | 连接件 | 宽度 | 跨缝长度 |
|---|---|---|---|---|
| ≤ `oblique_deg`（45） | 上缘 | 张开柱（顶端摊到 `w_top`，坡跟该处法向） | `post_w` 2.0 | `d_hit − top_clear`（默认离墙 2 层），坡根退进膜 `run` 里 |
| ≥ 180−`oblique_deg`（135） | 下缘 | 直条柱（长边竖直） | `post_b` 2.0 | `(缝 + embed)/cos`，直线底边 0.7 |
| 其余 | 侧边/斜边 | 薄墙片（长边水平） | `rib_w`（默认 `layer`＝一个层高） | `(缝 + embed)/cos`，厚 `rib_t`（默认 `skin`） |

- 岛（内环）走同一套判定，按轮廓面积符号翻 `flip`，否则岛的上缘会被打成直条柱。
- `oblique_deg=30` 的效果：36° 斜边从"下缘（2.0 竖直柱）"变成"侧边（0.4 横条）"。代价是那条边接触面积 10mm² → 1.6mm²，要更牢就把 `span_max` 压到 2.0。

## 5. 连接件几何

### 5.1 张开柱（上缘）

```
s_wide = d_hit - top_clear              # 贴墙端（离墙 2 层）
s_tip  = s_wide - run                   # 坡根（可为负，退进膜里）
a 半宽: s_tip 处 skin/2 (0.225) → s_wide 处 w_top/2 (1.30)，即 30° 楔形
沿边宽度: 恒 post_w/2 = 1.0，不随 s 变
```

- 楔形只往**墙厚方向**张开：贴墙端 `w_top`(2.6)、膜端 `skin`(0.45)，`grow=(w_top−skin)/2=1.075`、`run=grow/tan30°=1.862`。`s_tip<0` 时坡根退进膜里，靠体积重叠融合。
- 沿边宽度恒定 `post_w`=2.0：**没有加宽旋钮**。要更大的托面就多放柱（净跨 ≤ `span_max`），不要摊宽单颗柱——摊宽会让柱侧面变悬垂、相邻宽端互挤，见 §6。
- `flare_tack>0`：整颗牙朝口内平移 `embed+tack`，牙顶离墙 `tack`、不再咬墙（弱连接，撕时从牙尖断）；坡长与 `w_top` 不变，压膜那截变长。
- 张开柱的楔形压在膜上时把膜的 `[m0,m1]` 全包住，融合由体积重叠保证，与 `overlap` 无关。

### 5.2 下缘柱 / link 柱

宽 2.0、长边竖直（⊥ 水平面）、长 `(缝+embed)/cos` 算出、**杆顶停在膜端面不进膜**。`link_posts=True` 时判 link 的段用同一套竖直柱，但布点改成"两端各一颗 + 中间按 `start_gap=3.0` 均分"。

注意 `2.0 + 3.0 = 5.0 = span_max 3.0 + 宽 2.0`——判 link 的段与老规则布点几乎重合（矩形两种口径体积都是 91.97），差别只剩柱是竖的还是跟法向。

### 5.3 侧片

- `rib_w`（沿缝/切向，宽轴 = `up`）：决定切片里占几层。**默认 `layer`（一个层高），正好占 1 层**；老默认 `lw`=0.4 在 0.2 层高下占 2.25 层，等于在缝里立了一小堵 0.4 高的墙。
- `rib_t`（墙厚方向）：决定横向厚度。默认 = `skin`，与膜同厚同中，缝里那条线与膜直通到底。
- **默认就是只占一层**（`rib_w=None` → `layer`，柱心自动对层带中心），`rib_t` 保持默认；反过来把 `rib_t` 削到 0.2 会在膜与墙之间造一条 0.2 宽 0.45 长的细颈，切片排不下一整条线、走线偏一边（实测踩到，见 §8 第 19 条）。

## 6. 布点与净跨

- 布点沿**膜的收缩后轮廓**弧长，不是口轮廓——膜边已内缩 `g_used`，按口轮廓算会与柱脚错位。
- `k = ceil(L / (span_max + w))`，两端各一颗、各让 `w/2`；间距只按柱宽 `w` 定。
- **净跨 `clear_max = d − (w₁+w₂)/2`**：两根柱端面之间悬空的那段。膜的首条层带要桥它、**上方墙的底面也要桥它**，所以 3.0 这一个数对两头同时成立——这是唯一不能放宽的硬约束。
- `info["support"]` 每区给 `n / clear_max / cover / cover_len`；上缘另给 `contact_mm2 = post_w × w_top`（默认 5.2mm²）。`clear_max > span_max + 5e-3` 会进 `info["warn"]`（"净跨超标"），上缘一颗柱都没有也有告警。
- **补柱**：角格留空滤掉柱后，同一区内相邻两颗净跨仍 > `span_max` 时会按 `ceil(净跨/(span_max+w))` 插入补齐（落角格则跳过）。实测 blob down 段 4.77→1.38、波浪槽由超标收到 2.94 以内。
- 实测（0.08 层高，六种口）：上柱 31/14/41/25/24/8（矩形/圆/工字/拱顶/星/凹口），净跨 2.960/2.952/3.000/2.857/2.900/2.829，上缘覆盖率 0.082~0.132，单颗搭接恒 5.20mm²。

### 顶部接触面：只有墙厚方向

| 方向 | 值 | 说明 |
|---|---|---|
| 墙厚方向 `w_top` | `min(6.0, wall − lw)` = 2.6 | 30° 坡封顶。柱顶比膜厚 5 倍以上，上方墙底的第一层就落在这条 2.6 宽的窄条上——**这就是"加宽接触面"本体** |
| 沿边方向 | `post_w` = 2.0（恒定） | **没有加宽旋钮**。要让上方墙少桥只有多放柱（净跨 ≤ `span_max`） |

实测（layer 0.08，175×230 矩形口，上缘周长 155mm）：31 颗柱、净跨 2.960、单颗搭接 2.0×2.6 = 5.20mm²、上缘覆盖率 0.082。0.08~0.2 层高 × 六种口全部闭合单片。

**为什么不做沿边加宽（`flare_wx` 已删）**：①摊宽的柱侧面立刻变悬垂，坡度 `atan(wx/run)`（`run`=1.862），超 45° 塌边；②宽端相邻互挤——0.8 时端部净距只剩 0.36mm、1.5 时相碰，切片器会把它们填成一条连续悬檐；③早年按加宽后的宽度排点，柱数 31→24→20，加宽反而削弱膜上端锚点。**加一颗柱比摊宽一颗柱干净。**

### 口太窄闸门（`min_membrane`，默认 2.0mm）

口上最宽那一处的可打膜宽 = `2R − 2·g0`，`R` 是口内最大内切圆半径（96×96 网格 + 偶奇判内 + 点到所有边距离取最大）。小于 `min_membrane` 就**不出件**：`info["skipped"]="membrane_too_narrow"`，不抛错。

实测（layer 0.08、`min_membrane=2.0`）：净宽 1.2 → −0.013 跳过、2.4 → 1.175 跳过、3.0 → 1.768 跳过、3.4 → 生成。**为什么不用"逐边射线量宽度"**：窄槽的端边沿口长方向一路打到 100mm 外的另一头，会把 100×1.2 的槽算成 98.8 宽的膜放过去（实测踩到）。

## 7. 融合与撕脱

- 连接件**近端与膜边齐平**（`overlap=0`）、**远端埋进墙** `embed=0.1`。近端贴面也能被 manifold 布尔并成一片；**远端一旦也设 0 就会脱开**——实测拱顶裂成 11 片、异型带凹口 2 片。所以"两边都齐平"不成立。
- 近端齐平是刻意取舍：柱不往膜里多伸，代价是导出网格出现零面积面（见 §8 第 16 条）。要"一个整体"就给 `conn_fuse`（0.1~0.2），连接件穿进膜、先并成一块再并面板。
- 撕断点：远端埋进墙、近端并进膜，两侧都是 90° 内角，断点落在哪端由应力决定。要"窗口干净"得给连接件做缩颈，那是另一套代价。

## 8. 已踩过的失败模式

1. **膜悬空（`bodies ≥ 2`）**：连接件只到膜边、不重叠 → 膜整片脱落。靠**远端** `embed` 穿透墙 + **近端齐平**解决。**每次都要数连通体。**
2. **共面 ≠ 融合**：两个实体只共享一个面时 manifold 仍视为两个体。关键连接必须做体积重叠。
3. **切口溢出方向**：`overshoot` 只沿墙体法向，平面内不许溢出，否则口被放大、缝宽全错。
4. **张开凸出墙外**：张开断面超过墙厚会撞相邻件（历史实测 0.055 cm³ 干涉）。`w_top` 已内置封顶。
5. **只封了一面**：中段/外套这类前后两面都露在外面的件，两面各做一份。
6. **非流形边（重载后 `watertight=False`）**：STL 是 float32。→ `clean_export()`，导出后重新载入复查。
7. **统计连通体用错 API**：本机 trimesh 无 graph 引擎，`mesh.split()` 抛 `no graph engines available`。→ 用 `manifold3d.Manifold(...).decompose()`。
8. **把封膜的口当出口**：膜 + 缝挡不住纸包，若索引里是"出包口"，必须先告知"要捅破/剪开"。
9. **窄处残条**：窄口收窄（`g_used < 3×layer`）时若仍按 `3×layer` 切上缘环带，会留一条 `(3×layer − g_used)` 的膜残条。现在按 `4×layer − g_used` 挪边线，缝宽恒为 `4×layer`，无残条。
10. **上缘一弯，膜被割碎**：早期用「逐段 quad 并集 + 端头沿切线外伸」切环带，只有上缘是单一直段时环带内边才与膜 miter 轮廓重合；拱顶/正弦波/斜切时逐段错开，膜被割成锯齿乃至碎块（实测拱顶 1→4 片、正弦波顶 1→11 片，布尔随即报 `Not all meshes are volumes`）。已改为**先挪上缘边线再统一 offset 一次**，七种上缘形状（矩形/梯形/拱顶/正弦波/浅V/凹口/岛环）全部 `bodies=1`。
11. **收窄与张开互斥**：窄口 + 张开会在加宽处把膜刮光并**报错**（正确行为）。判据：局部净宽 ≥ `g_used + 4×layer + 最小残留膜宽`；标准参数下 ≈1.8mm，而收窄只在 ≤1.2mm 发生，两区间不相交。窄口要么放宽，要么 `flare=False`。
12. **`flare=False` 的缝宽**：不张开时上缘必须回落到 `g_used`，不能仍用 `4×layer`，否则柱会多埋进墙 `(gap_up − g_used)`。已按此实现。
13. **膜被割碎是静默的**：早期加宽后只查 `is_empty()`，膜裂成几片照样放行，现象伪装成"柱子生成得奇怪"。现在 `num_contour` 必须等于输入环数，否则报错并给出判据与两条出路。
14. **起膜边悬空下垂 → 该段柱加密（已落地）**：膜在水平面上方 0.6 处起步，首层下垂 ≈1 层高（0.2），余量只剩 0.4；且 0.6 < `gap_fill=0.8` 落在切片器间隙填充区间。**一律加宽到 `5×layer` 已被否**（不符合"两类缝宽"，倒三角这类膜边也不需要）。已实现的是 `link_posts=True`：柱是竖直柱、宽 2.0 定死、长按缝算（直线底边 0.7）、杆顶停在膜端面、先落两端各一颗、剩余净长按柱间空 3.0 均分。实测：方形口 100×100 起膜边 20 颗 @4.9；工字形 v=30 24 颗 @4.92、v=220 两段各 8；圆形口 13 颗 @5.0 且斜位置仍竖直。缝仍在。
    - 撤掉的候选：**合缝**（朝外拉长 `g+embed` 落到下方材料，首层不悬空但缝整条消失，用户看过图后改主意要柱子）；**全墙厚厚条**（悬在 0.6 空档上的台子，只看第一版图即否）。
15. **窄通道把膜整条抹掉 → 已改为显式报错**：相对两条边净距 < `两侧缝宽 + lw`（算例 0.6+0.8+0.4 = 1.8）时，内缩后那段膜整条消失而 `num_contour` 不变。早先 h 扫描：h=1.2/1.4 上方全空、1.6 只剩极窄一条、1.8/2.0 窄条且位置漂移、≥2.5 正常，全程不报错。现在 `_check_too_narrow()` 在 `_shrink` **之前**也跑一次（用 `g0`），直接抛"离顶部过窄"并给出所需净宽与两条边的差值。→ 遇到就改形状，不要指望膜自己活下来。
16. **「完全共面」会带来零面积面与 4 面边，但不是缺陷（口径已改）**：连接件顶面/底面与膜同厚齐平、端面与膜端面共面时，manifold 把共面区并成一块后三角化，会吐出零面积楔形与重复面。实测：矩形/圆形/异型/岛环/拱顶 **0 个**；工字形（有凹角）**164 个零面积面 + 15 条 4 面边**，全压在 v=60/v=220 两排柱的直线上，`bodies` 仍 1、体积不变。柱沿厚度各缩 0.002 会降到 11 个，但柱面比膜面低 0.002 出现浅槽——不值。**零面积三角形不能删**：删掉立刻开出 184 条边界边（它们本身在堵缝）。判缺陷用 `closed`（无 1 面边界边）+ `bodies==1`，`watertight` 只作参考。
17. **凹角那颗柱必须留空（已落地）**：凹角处材料只占一个象限，角格 `g×g` 之外就是材料；柱宽 2.0 大于角格，要连墙只能从侧面钻进墙角 0.1。→ `_stations()` 认凹角（叉积符号 × 环面积符号 < 0）后两侧都不放柱，角格留空，由两臂最近的柱夹住。凸角不受影响。
18. **侧片削薄（`rib_t`）与张开柱离墙（`flare_tack`）**——两条都是使用者提的显式口径，默认都关。加完后 `demo-poly` 十二例逐位一致。
    - `rib_t=0.2`：侧片居中、沿边宽仍 `lw`、跨缝长仍 0.7，与膜相接两侧各留 0.125 台阶；R40 实测 35 片、`bodies=1`、17.176 cm³（同厚版 17.1786）。片薄后是**单层悬带**，跨 0.6 只当短桥。**口径已收回**：0.2 比线宽窄，切片排线只能贴边 → 走线偏一边，见第 19 条。
    - `flare_tack=0.16`：`s_far = 4×layer − tack`，坡长恒 = `run`，牙整体朝口内平移 `embed+tack`，`w_top` 与 30° 都不变；牙顶离墙 0.16、不再咬墙。R40 实测 14 颗、17.181 cm³，`bodies=1`。此时上缘只挂在膜上，撕脱从顶边起。
    - **打印关**：`tack < 层高` 时能不能真断开取决于空档落在哪一层。正对顶部那颗实测牙顶 Z=89.84、墙面 90.0、层边界 89.8/90.0 → 空一整层，能断；±40° 那几颗空档是斜的，竖直只剩 ≈0.11，层内成 0.16 窄条会被间隙填充（`0.9`）焊上。要整圈都断：关间隙填充，或 `flare_tack` 提到 0.2~0.25。
19. **侧片"一层"到底该削哪个方向（`rib_w`/`rib_snap`）**：`rib_t` 削的是**墙厚方向**（横向，切片里看不出层数）；侧片的宽度轴就是 `up`，`lw` 0.4 / 层高 0.2 = 2.25 层，压进 3 个层带。要"只占一层"得削 `rib_w`：
    - `rib_w=layer` 0.2 → 断面 0.2×0.2，R40 实测侧片 35→37 片、净空 3.0~3.26、`bodies=1`、17.1803 cm³（比 0.45×0.2 版少 1mm³）。
    - `rib_snap=True` → 柱心沿轮廓挪到 `(k+0.5)×layer`，R40 实测 37/37 全落层带中心；STL 里侧片外侧面的 Z 起止正好 `119×0.2` 与 `376×0.2`。
    - **只能沿切向挪**：`Δs = Δh/(切向·up)`；法向挪会改跨缝长度。侧弧 `切向·up` 在 0.707~1，最大挪 0.14。离段端 `w/2` 以内那颗不挪（保"端面与膜端面共面"）。
    - ±40° 处沿口切向的竖直分量只有 ≈0.77，0.2 宽在那里只占 0.15 层——"每处都正好一层"做不到全覆盖。
    - **`rib_t=layer` 要收回**：等于在膜与墙之间造一条 0.2 宽 0.45 长的细颈，切片排不下一整条 0.45 的线，只能贴细颈一侧对齐 → 现象就是"薄墙喷头走线朝一边歪"，那层膜与墙之间也不再是直通墙。正确做法：`rib_t` 保持默认、`rib_w=layer` + `rib_snap`。R40 实测（`rib_w=0.2, rib_t=None, conn_fuse=0.15`）：37 片、17.1815 cm³、`bodies=1`。
20. **连接件与膜不许"共面对接"（`conn_fuse`）**：老口径裁到膜端面为止，两者共面贴合，界面处是一对重合面（导出 STL 表现为 2 条 4 面边），切片器可能把 0.2 的连接件当**独立薄壁**单独排线（线宽塞不进 0.2，只能偏一边）。`conn_fuse>0` 时裁切用的膜整体内缩，连接件穿进膜 0.1~0.2，先并成一块再并面板：`fill` 从 16 片降到 **1 片**；R40 同参数 17.1803 → 17.1815（差 0.0012 cm³ 只是界面那点重叠）。内缩后 `num_contour` 不等于原值就退回不缩（薄岛/窄环要当心）。
21. **斜边被算成"下缘"，同一件上竖柱与横条混着（星形实测，用户指出）**：45° 容差把 36° 斜边（`dot=−0.81`）划到下缘，放 2.0 竖直柱；紧邻的 72° 边算侧边放横条，肉眼就是"一条竖柱、旁边一条横条"。`oblique_deg=30` 让 ≥30° 斜边统一走横条。**连带影响**：斜边从 down 变 side 后，水平上缘的端柱不再让位（每段 5→6 颗），侧片 33→68 颗。接触面积 10mm² → 1.6mm²。
22. **柱端面压在尖角上 → 左右侧面插进墙里（星形实测，用户指出"张开柱左侧也贴墙"）**：36° 尖角处缝是个 V（膜尖端离口尖 1.94），2.0 宽柱端面压在尖角上时左右侧面在 V 两臂各插进墙一截，`flare_tack` 只管末端空档、管不到侧面。`tip_deg=60` 后尖角两侧都不留端柱（最近件退到 3.17）。**顺带修一个老 bug**：`keep_first/keep_last` 只处理区段两端的角，同一区段内部拐过去的角管不到——星形两条斜边都是 side，顶角与底中 252° 角都在区段内部，各漏 1 片（距角 0.04/0.07，端面直接插进墙）。现在按弧长再滤一遍（件端面到角点 < `tack`）。**环境依赖**：`reflex_v`/`sharp_v`/`cum` 都在旋转后的 ring 上算，索引必须一致。
23. **尖角处"端面在膜端点 + 侧面不跨过膜"只能靠随形楔（用户第二轮批注）**：矩形柱做不到——36° 尖角处膜宽为 0，任何宽度 >0 的柱端面放到膜顶点，左右两角就落在膜外插进墙（实测宽 1.0 的窄柱也越界）。楔的做法：顶点沿角平分线往膜里退 `conn_fuse`，两条边与膜两臂平行（各内收 `fuse`），长 `L=(g+embed)/sin(半角)+fuse`（36° ≈2.41），厚度与膜同。**为什么早先尖角上"没有柱"**：① 布点端柱按半柱宽内缩，区段端点落在尖角时柱端面就压在顶点上；② 更早那颗被**拐角让位规则**剔掉（一个拐角只留一颗，同宽 `down > up > side`）；③ 斜边改横条后邻居变窄、张开柱不再让位，于是又回到尖角上并插墙。`reflex_v` 的"角格留空"只判内角 >180° 的凹角。
24. **楔被否 → 尖角件按"横条同尺寸 + 轴对齐"落地（用户第四轮批注：不要填 V，用一个连接件把尖角与墙连起来，尺寸跟其他连接件同一套逻辑，也要保持水平，下尖横、上尖不横）**：断面取 `rib_w`×膜厚，长度用 `_march_out()` 从膜尖点量到**窗口外环**再 +`tip_embed`；轴线只在 up/hz 里选，上尖竖直、其余水平。**别用"离膜边界 ≥ 缝宽"当量长判据**——尖角是折线顶点，膜外一点的最近点就是那个顶点，会在缝里提前停住（实测顶尖只走到 0.7、根本没碰墙）。两端都不咬合（`tip_embed=0, tip_overlap=0`，**使用者定版，不许再改**）：与墙靠端面楔形切进墙料仍有体积重叠、`bodies=1`；与膜只剩膜尖一点接触（探针 dz=−0.05 处、x=膜尖−0.03 已是空），膜尖打印上孤立——**该代价使用者已当面接受**。

- **27. 沉台/台阶件上做「随形托」**：思路成立（先建大、再拿真实孔腔裁），但孔腔必须闭合；非水密件裁出来是毛边，且"裁短"与"没托到"在切片里分不出来。现行改为闸门跳过（§11.7）。
- **28. `_detect_wall` 取「最近的平行面」当背面**：沉台底只有 626mm² 也会压过 54902mm² 的整张背面，T 被量成 2.2，后面缝宽、柱位全错。已改成**面积优先**（同 `frac>=0.5` 的候选里取面积最大者）。

### v2 实现层面踩到的几条（已修，别再犯）

- **剖面元组顺序**：`_profile` 返回 `(剖面, s_tip)`，剖面点是 `(s, a)`（`s` 沿缝、`a` 沿墙厚）。写反会得到"厚度方向错位 1.5mm 的柱"，`bodies` 直接炸开。
- **换轴是镜像**：`(X,Y,Z) → (u,a,v)` 这类置换行列式为 −1，必须翻面，否则体积为负、布尔报 `Not all meshes are volumes`。
- **退化剖面**：`run` 恰好等于缝宽时直段长度为 0，出现重合点 → 非水密。`_sweep_prof` 里已有去重。
- **内环判定要镜像**：孔环的材料在外侧，`(dy,−dx)` 指向的是岛而不是缝，"上缘"与"下缘"会整体反掉。按轮廓面积符号取 `flip`。
- **挪边线的顶点要截断**：上缘段往口内挪、邻段不挪时顶点是两条移位后直线的交点；两段近乎共线时交点会飞出去（尖角处更甚）。按 `|交点−原顶点| ≤ miter_limit × 移位量` 判，超了就用平均位移，否则移出来的折线自交、offset 又把它抹平。
- **尖角被误判"离顶部过窄"（五角星实测，已修）**：`_check_too_narrow` 用"两段外法向夹角 >135°"认"相对的两条边"。尖角处相邻两边的外法向差 = 180°−尖角，**36° 的星尖就是 144°（dot=−0.81）**，被当成相对边、两段还共用顶点 → 直接抛"两条相对的边只隔 0.000"。修法：两段只要共用顶点就不参与判定。回归里 `五角星_尖角凹角` 钉住它。
- **默认参数下的崩溃**：`tip_mode=bar/zone` 且 `rib_w=None` 时 `0.5*spec.rib_w` 抛 TypeError。→ `_rib_w()` 统一退到 `layer`（一个层高）。

### 预览脚本踩到的几条（已修）

- **画家算法不可用**：3mm 薄板用 `Poly3DCollection` 的 `zsort` 会出假遮挡与摩尔纹，看着像零件破了。改为深度缓冲光栅化，只出正投影/剖切。
- **裁切不能筛面片**：布尔后的大三角形质心在框里、顶点却横跨整块板，按质心筛会把视野撑回全宽。→ 只用裁切框定视野，靠像素边界与 z-buffer 截断。
- **剖面不能按线段中点裁**：横跨整个口的长边中点可能落在视野外，整条被丢掉，剖面变空白。→ 只设 xlim/ylim，让 matplotlib 自己裁。
- **光照过曝**：`0.34+0.62×inten` 会把受光面画成纯白，像漏画的洞。→ 压到 `0.46+0.42×inten` 并叠景深色调。
- **trimesh 5.2 剖切签名变了**：`trimesh.intersections.mesh_plane` 新签名是 `(mesh, plane_normal, plane_origin)`，脚本按旧版传 `(mesh, origin, normal)`，剖出来的面跑到别处（实测 X=50 切到 X=1.0）。包一层对调两个参数再喂 `section_2d`。
- **依赖**：只需要 matplotlib / PIL / trimesh / manifold3d，**没有** pyglet、pyrender、scipy。不要用 `slice_mesh_plane`（要 scipy），用 `mesh_plane` 取线段。

25. **曲口当直线口打**：不规则曲线孔直接喂 `window_poly`，会得到「每 2 段一颗柱」的柱排、或整条弧没柱。必须 `corner_deg=20`（默认已开）+ 必要时 `var_gap=True`。判据看 info 里 `support` 的柱数是否随周长线性长（R40 圆约 14 颗上柱，若上百颗就是假区段没被合并）。
26. **负体积壳混进 `bodies`**：变宽口张开柱坡根穿出薄膜会切出里朝外的碎片，`simplify` 去不掉。`clean_export` 的 `_drop_inverted` 只剔负体积分量，正体积脱落仍报错。

## 11. 曲线口与变宽口

### 11.1 三个新旋钮

| 参数 | 默认 | 作用 |
|---|---|---|
| `corner_deg` | 20.0 | 相邻切线夹角 > 该值才算**真拐角**。0 = 老口径（每个顶点都是拐角，圆弧上会疯狂误判） |
| `var_gap` | False | 逐段压缝。False = 恒定缝宽老路径，回归逐位不变 |
| （派生）`_clamp_frac` | — | 缝被压到 `slot_min` 以下的边占周长比例，> 0.5 直接拒绝 |

### 11.2 曲的口为什么会坏

1. **假区段**：`dot(n, up) = cos(oblique_deg)` 的容差带里，几百段圆弧的外法向抖动 → 每 2~3 段就切一次区 → 每段两端各落一颗端柱。修法：`_stations` 里把短于 `min_run = max(1.0, 1.5·g_used)` 的区段并进较长邻居，重建到稳定（≤64 轮），用 `_arc(i0,i1)` 算弧长。
2. **假拐角**：`reflex_v` / `sharp_v` 原来按"顶点存在"判，凹弧每个顶点都被判凹角（角格留空 → 整条弧没柱），凸弧每个顶点又都是区段界（"只留一颗" → 柱被削光）。改成先算 `corner_v[i] = turn[i] > corner_deg`，`reflex_v = corner_v and 凹`、`sharp_v = corner_v and tip_deg and 尖角 < tip_deg`。直线多边形所有角 > 20°，行为不变。
3. **窄端自交**：恒定缝宽的 `_shrink` 在窄端缝比口还宽 → offset 自交 → 膜碎、`bodies=5`、`残留膜过窄 -0.3`。

### 11.3 `var_gap` 的算法

```python
W_i   = 段中点沿内法向到对边的距离          # _edge_width
want  = gap_up if 上缘 else g0              # 与恒定缝宽同一套
g_i   = min(want, max(0.05, (W_i - max(lw, skin)) / 2))
uniform = all(g_i == want)                  # 一段没压 → 走原路径
```

- `uniform=True` → 完全走老路径（`_check_too_narrow` / `_shrink` / `_min_residual` / `_widen_up`），十二例体积逐位不变；
- `uniform=False` → `_membrane_var` 逐段偏移出膜，跳过收窄全流程，`g_used = min(g_i)`；
- 窄端 `g_i < slot_min`：该处膜与墙粘牢（切片器会填），等效窄端实心，`warn` 报"窄端不放柱"；
- `_clamp_frac > 0.5` → `ValueError("这个口整体太窄…")`。

### 11.4 柱长：从公式改射线

变宽口不能再用 `(g+embed)/cos`——它取到最窄处的 `g`，宽处的柱够不到墙。改成：

```python
d_hit = _hit_dist(open_pts, pt, seam)      # 柱脚沿法向射线量到墙
s_end = (d_hit + embed) / max(0.35, cosv)  # up / side（沿轴长，要除 cosv）
s_end = d_hit + embed                      # seam（沿法向长，不除）
```

三个坑：①`variance` 返回值是 **uniform**，`if uniform:` 会把常规口送进变宽路径（写反 → 工字 `bodies=3`）；②`d_hit` 是沿 seam 量的，`up`/`side` 柱沿轴长，必须 `(d_hit+embed)/cosv`，写成 `d_hit + embed/cosv` 会让柱短一截（齿轮/新月 `bodies=2`）；③张开柱坡根 `s_tip = s_wide - run` 常为负，窄端膜只有 0.45 宽时坡根从另一面穿出 → 被膜裁成**负体积悬空片**。用 `d_far = _hit_dist(open_pts, pt, -seam)` 估局部膜宽，`-s_tip > d_far - d_hit` 就跳过该柱。

### 11.5 负体积壳

坡根穿膜会在布尔结果里留下里朝外的碎片（`vol ≈ -0.001 cm³`），`simplify(1e-4/1e-3/1e-2)` 都去不掉，`check()` 会把它算进 `bodies`。`clean_export` 现在先过 `_drop_inverted(mesh)`：`decompose()` 后只保留非负体积分量再 union。**只剔负体积**——正体积分体（真脱落）仍然报错，不会被悄悄吞掉。

### 11.5b 膜边碎屑（`_drop_tiny`）

变宽口尖角上，膜的逐段偏移会削下 0.1~0.3 mm³ 的小薄片：面片合法、`closed=True`、`bodies` 虚高，但打不出来。`window_poly` 组 `fill` 时过 `_drop_tiny(mesh, 1.0)`（阈值 1 mm³）：

- 体积 < 1 mm³ 的分量剔除，`warn` 报 `膜边碎屑`（实测新月 2 片、椭圆/圆/blob/齿轮/泪滴各 1 片、五角星 1 片 ≈ 0.01 cm³）；
- 剔除后仍 > 1 块 → `warn` 报 `连接件未连到膜`（这是真缺陷：柱只搭在墙上、没焊到膜）；
- 阈值以内不会吞掉真连接件（单颗张开柱 7 mm³ 量级）。

修前新月 `fill`（膜+柱、不含面板）是 **3 块**，修后 1 块；最终件体积基本不变（五角星当时 156.76→156.75；后来补柱又把角上那颗补回来，现在是 156.76）。

### 11.7 上方墙底面比口边深：直接不生成（`stl_window.py` 的闸门）

问过使用者：既然输入永远是 STL，那就**按 STL 量**——上方墙底面如果比口边更往里，这套「膜 + 托」托不到它，直接不出件（B 口径，不做随形）。

做法（`_ceiling_probe` / `_recess_verdict`）：在所选面的 `up` 边上按弧长取 16 个采样点，各往外让 0.14mm、插一根 0.18×0.18 的细柱（贯穿墙厚 ±0.25），与原件求交，得到该点「材料沿墙厚的区间 `[y0, y1]`」。三条闸门：

| 判据 | 含义 | 报错 |
|---|---|---|
| `max(y0) > --recess-tol`（默认 0.05） | 材料起点比口边那张面更深 | `[跳过] 上方墙底面比口边深 X.XXmm` |
| `min(y1-y0) < w_top` | 上方材料不够厚，张开柱摊不进墙 | `[跳过] 上方墙在那处只剩 X.XXmm 厚` |
| 半数以上采样点打空 | 口上缘外面根本没墙 | `[跳过] 上方没有墙` |

实测（240×3×240 面板，60×44 椭圆通孔，0.08 层高）：

- 正常件：材料区间全 `Y 0.000..3.000` → 生成，closed/bodies=1、167.53cm³；
- 上缘外挖 0.8mm 深沉台（宽 72、高 10）：12 个采样点变成 `Y 0.800..3.000` → **跳过**，`--no-recess-check` 可强行出件。

为什么不随形（这是权衡，不是偷懒）：能随形的做法是把柱先建长建宽、再与**真实孔腔**求交（`孔腔 = 直棱柱 - 原件`），顶面就会贴住任意凹形；代价是孔腔必须是闭合实体，非水密件裁出来是毛边，而且"裁短了"与"没托到"在切片里长得一样。所以现行版本选了"报出来、不生成"，把决定权留给人。

### 11.8 STL 前端的自愈、薄壁合并与楔尖剪除

| 步骤 | 触发 | 行为 | 参数 |
|---|---|---|---|
| 自愈 | 载入后 `is_watertight == False` | 按位置焊接重合顶点 + 重建拓扑；失败时报边界边/非流形边条数 | 无（默认开） |
| 薄壁合并 | 截面规整 | 并自交/重叠环后做开运算（腐蚀 t/2 再膨胀 t/2），薄于 t 的材料整块消失 | `--merge-thin`，默认 `1.2×lw` = 0.48mm |
| 楔尖岛剪除 | 岛与孔边（或岛之间）净距 < `2×gap_up+lw` | 该岛当"膜过不去"删掉 | `--no-split-pinch` 关 |
| 窄颈弦切 | 孔轮廓上两段平行边净距 < 同上阈值 | 在最窄两点拉弦，拆成两个独立子口分别出膜 | 同上 |

判「窄颈」要同时满足三条（否则普通凸边、三角化毛刺会被误判）：两段边基本平行（叉积 < 0.3）、两点连线基本垂直于这两段边（|cos| < 0.3）、沿环弧长相差 ≥ 3mm；且切开后两块面积都要 ≥ 4mm²，否则不切。

**踩坑 29**：从 STL 截出来的孔环，绕向不定。`_ceiling_probe` 原来只朝 `+nout[i]`（环边外法向）偏移 0.14mm，法向朝里时 16 个探针全落在空气里，于是每个孔都报「上方没有墙」。改成两侧都试（`±nout`），取有材料且材料起点更浅的那一侧。

**踩坑 30**：沉台/凸台件上，"最近的平行面"常常不是背面。某件背面 54901.6mm²，沉台底 626.5mm²，取最近面把 T 量成 2.200（实际 3.000），缝宽和柱位全错。定厚改成在"反向平行"候选里按 `max(面积, −T)` 选，面积优先。

**踩坑 31**：孔与孔"相切/浅重叠"时，`_check_too_narrow` 报的"两条相对的边只隔 0.08~0.5mm"不是均匀薄壁，而是两个圆之间留下的**刀口楔**（最厚 1~1.6mm、尖端趋 0）。靠开运算（`--merge-thin` 抬到 1.0）删不掉——那要腐蚀 0.5mm，会把截环拓扑搞崩（判不出孔）。正确做法是**认楔尖**：把与孔边净距小于阈值的岛当不存在（本工具默认行为），比按厚度阈值开运算稳。

**踩坑 32**：托的顶隙不是越大越好，也不是越小越好。给 0 = 埋进墙（`embed` 0.1），托与上方墙熔成一块，拆的时候带墙皮；给 `2×layer`（0.08 → 0.16）= 下垂被挡在 2 层内、又不熔死；**小于一个层高**（0.08 层高给 0.05）会被切片器当间隙填充焊上，等于没留；**大于 `w_top/2`**（1.3）托端就够不到悬垂面的下垂范围，等于没托。另外它让托与墙**没有体积重叠**——连通性全靠坡根压进膜，改 `top_clear` 后必须数一次 `bodies`。

## 12. 口径备忘（定版）

- 上缘缝宽 `max(4×layer, g0+layer)`，**不由坡度反算**；其余缝宽 `max(3×layer, 1.5×lw)`。
- 坡度守 30°，斜坡允许退进膜面内（`s_tip` 可为负），最宽仍到 `w_top`。
- **`flare_tack` 不是废项**：给了就是弱连接，不给就埋墙 `embed`。
- **一切决策都要过打印这一关**：起膜边悬空下垂、缝窄被间隙填充、相对边净距不足会漏膜——三条都是"几何对、打不出来"。
- 起膜边**不加宽**：下垂由「判 link 的段用竖直柱 宽 2.0 / 长按缝算 / 柱间空 3.0」解决，缝留着。**全墙厚厚条**、**合缝**、**0.7 宽距 3.0 的加密**、**1.0 宽沿边扁柱**、**径向辐条**、**柱长定死 2.0** 六版都撤了。
- **方向按打印轴，不跟缝的法向**：下缘柱一律竖直、侧边片一律水平，只有上缘张开柱跟该处 30° 坡。轴对齐件整体按膜裁一刀，杆顶自然停在膜端面。
- **柱宽一律 2.0**（`post_w`/`post_b`），薄墙片 `rib_w` 默认 `lw`。柱长不用填：下缘/侧边按 `(缝+embed)/cos` 算出，上缘按 `run` 算出。
- **顶部接触面只有墙厚方向**：`w_top`(2.6) 就是托面宽度；沿边恒 `post_w` 2.0，**没有加宽旋钮**，要更大的托面就加柱。
- **净跨只有一个口径** `clear_max`：膜首层与上方墙桥的是同一段长度。
- 段界那颗落在拐角上（柱心离段端 `w/2`，柱面与膜端面共面，不越过拐角、也不退进去留空腔）。
- 上缘加宽的实现是「挪上缘边线 `gap_up − g_used` → 统一 offset 一次」，不切环带。
- 预览走独立 `preview.py`，不往几何模块里塞渲染。
- **侧片两个横向尺寸都跟打印参数走**：`rib_w`（切向/宽轴=up，决定占几层）默认 `lw`，`rib_t`（墙厚方向）默认 `skin`。要一层就 `rib_w=layer`+`rib_snap`，**别削 `rib_t`**。
- **能跟层高/线宽走的都不要写死毫米数**：`rib_w`、`flare_tack_k=0.8`、`conn_fuse_k=1/3`、缝 3×layer/4×layer、`slot_min=1.5×lw`。只有 `embed` 0.1 这类"咬墙深度"按绝对值留。
- 张开柱末端**默认离墙 0.16mm**（`top_clear` 写死，不随层高变），不与悬垂面熔死；`top_clear=0` 才回到「埋进墙 `embed`」的老口径。`flare_tack` 是另一层意思（弱连接），两者不要同时用来调同一件事。
- **§8 第 24 条的尖角件口径（`tip_embed=0, tip_overlap=0`）是使用者当面定版，不许再改。**
